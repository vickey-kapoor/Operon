read_file(path): read a text file (.txt, .csv, .log, .ini, .json, .md) without opening it in an app.
- Use it to read data you need, instead of opening the file and scrolling.
- Pictures (.png, .jpg, .svg) and documents shown in an app are for your eyes: open them and read the screen.
- Example: read_file(path="Documents/orders.csv"), then work out the totals yourself.
